# Features

기능별 도메인 모듈을 모아두는 폴더입니다. 각 폴더는 UI 컴포넌트, hooks, server actions, types를 자급자족합니다.

| 폴더 | 책임 | 단계 |
|---|---|---|
| `auth/` | Supabase Auth 회원가입/로그인/세션 | Phase 1 |
| `cards/` | 카드 데이터 모델, 시드, 조회 | Phase 2 |
| `srs/` | FSRS 알고리즘, 복습 큐 생성, 평가 처리 | Phase 3 |
| `conversation/` | AI 회화 시뮬레이션 (Gemini) | Phase 5 |
| `progress/` | 학습 진도, 스트릭, 통계 | Phase 6 |
